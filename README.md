Project Name: AniMazing
Project Description:
    AniMazing is a web-based platform designed to allow users to search for information about their 
    favorite anime and manga they want to keep track of. Users can search through the Maze for their
    favorite anime and manga, add them to their Map to revisit them, and assign ratings to them.

__List of Features Implemented__
- Signup / Login: Fully functional creation of an account and ability to access it.
- The Maze: A fully searchable and sortable view of the anime and manga database.
- The Map: A customizable list of entries from the maze that the user can assign ratings to.
- The Profile: A page to view other users' stats as well as change settings related to the user's
    account.
- Content Pages: A page which automatically gets the information for a specific entry.
- Dynamic Rendering: Almost any page can be viewed by the user and will change depending on if the
    user is logged in or not.
- Light Mode: A secondary color scheme to improve accessibility. Available to toggle from the profile

__List of Features Not Implemented__
- Notification Center
- Custom error page

__Known Bugs or Limitations__
Some graphical errors on resizing
